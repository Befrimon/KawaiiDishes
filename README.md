Original mod: [Kawaii Dishes](https://modrinth.com/mod/kawaii-dishes)

This mod is a fork of the original KawaiiDishes (1.10.2) designed to make the content purely cosmetic and less overpowered.

**Key Changes:**
- Cosmetic Armor: Removed armor stats and defense values from cosmetic items.
- No Status Effects: Eating the food or wearing the armor sets no longer grants potion effects.
- Recipe Tweaks: Changed the crafting recipe for the Golden Cookie.
- Localization: Added full Russian language support.

_Note: Generative AI was used during the creation of this mod._

Оригинальный мод: [Kawaii Dishes](https://modrinth.com/mod/kawaii-dishes)

Этот мод представляет собой форк оригинального KawaiiDishes (1.10.2), созданный с целью сделать весь контент исключительно косметическим и убрать излишнюю мощь предметов. 

**Основные изменения:**
- Косметическая броня: Убрана защита и другие характеристики брони у косметических предметов.
- Без статус-эффектов: Поедание еды и ношение комплектов брони больше не накладывает эффекты зелий.
- Изменения рецептов: Изменен рецепт крафта Золотого печенья.
- Локализация: Добавлена полная поддержка русского языка.

_Примечание: При создании этого мода использовалась генеративная нейросеть._
